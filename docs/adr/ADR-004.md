# ADR-004：S2 Rows Block 改为页容器，PageSize=32 KiB

- 状态：已接受（2026-09-09）
- 关联规范：[BINARY_FORMAT_V2.md](../BINARY_FORMAT_V2.md) §5.1、[FILE_FORMAT_REFACTOR_PLAN.md](../FILE_FORMAT_REFACTOR_PLAN.md) §6

## 背景

v1/v2（S0 冻结基线）的 Rows Block 是整块压缩：读一行也读取、解压、校验整个 256 KiB
Block，冷点读存在明显读放大（rawB/op 327,095 ≈ 319 KiB）、CPU（zstd 51.5% + CRC
18.2%）和临时内存分配（无池口径 328,645 B/op）。S2 需要把压缩/校验单位从 Block 降到 Page。

## 决策

1. **Rows Block 改为页容器**：逻辑块（写入/统计/快照组织单位）与物理压缩页（读取/解压/
   缓存单位）分离。块 payload = `[RowsBlockHeader][RowsPageDirEntry×N][stored 页...]`。
2. **外层 BlockHeader 只做聚合**：`RawSize=Σ页raw`、`StoredSize=容器长`、
   `RawCRC32C=容器[头+目录]明文CRC`；各页由自身 PageCRC 校验，块级不再有整载荷 raw CRC。
   页目录保持明文，供读取器不需解密整块即可定位页。
3. **PageSize 冻结为 32 KiB**：S2 原型矩阵（5 列混合 200k 行）16/32/64/128 KiB 的
   storedB/row = 14.78/13.50/12.80/12.52、ratio = 0.128/0.117/0.111/0.109；32 KiB 相对
   64 KiB 仅损失 ~7% 压缩率，但单次冷读解压从 64 KiB 减半。PageSize 是建库后不可变的
   写时分页参数，读取按目录定位页，不需要它（BINARY_FORMAT_V2 §5.1）。读取侧 Open 参数
   不能伪装成另一种 PageSize。
4. **单行读页级 I/O**：plain 块先读块头+容器头+页目录，再按 ItemOrdinal→页只拉取该页
   stored 字节并解压；加密块本阶段保留整容器密封（目录在密文内），逐页 nonce 域分离为
   下一提交。
5. **O(1) 记录索引**：RowsPage 解析时构建 ids/ends/vers 每记录索引（随 CRC 校验一起
   验证 varint 边界），RecordAt/Records 由 O(ordinal) 流遍历降为 O(1)，热点读不因
   页格式而退化。
6. **逐页加密**（BINARY_FORMAT_V2 §5.2）：Rows Block 每页独立 AES-256-GCM 密封，
   nonce 由 HMAC-SHA256 派生自独立 page-nonce 子密钥并绑定
   StoreUUID/SnapshotID/BlockID/PageOrdinal/KeyEpoch，AAD 绑定页目录字段；页目录保持
   明文，读取只 OPEN 所访问的那一页（加密块也享受页级 I/O）。Metadata Block 仍整容器
   密封。域分离测试见 `internal/seal/seal_page_test.go`。
7. **一刀切**：不保留旧 RowsPayload 读写分支、不做双格式分派（旧 RowsPayload/旧 parse
   函数为 S5 清理内容，S2 不在读路径使用）。

## 后果

收益（同机同口径，S2 直读档 20k 行，对照 `docs/baseline/` S0 冻结值）：

- 冷读无池临时分配 328,645 B/op → **57,932 B/op**（≤ 64 KiB 门槛）。
- 冷读 rawB/op 327,095 → **32,778 B**（只解压一页），readB/op 62,843 → 5,845。
- 冷点读延迟 ~349 µs → ~48 µs（≥ 4x，实际 ~7x）。
- 热点读 277 ns → 246 ns（≤ 125%，实际 ~89%），O(1) 记录索引避免了每调用重复解压。
- 写吞吐 104.2 ms → 87.3 ms（≥ 90%）；Scan 100k 13.6 ms → 13.5 ms（0 alloc/row）。
- golden 样本变小（页格式去掉逐行 RowDirectoryEntry+RowRecordHeader 冗余）。

代价：

- 每页多一份 ids/ends/vers 内存索引（~12 B/行/页的随机访问成本），缓存容器实际内存
  高于 `StoredLen()` 记账（后续改进记账）。
- 每页 AES-GCM 密封使加密写吞吐约 2 倍于明文（实测 `BenchmarkEncryptedWrite` ~180 ms
  vs 明文 `BenchmarkWriteFull` ~87 ms）；加密热点读 ~283 ns vs 明文 ~255 ns（加密增量
  ~11%），加密冷读由于整页 OPEN 仍为页级 I/O。加密增量成本单独报告。
- 一次性列流编码（schema RLE / change 2bit / offset delta）使 RecordAt 从 O(1) 目录访问
  变为需要页索引，为保持热门读性能引入每页索引开销。

## 备选

- 16 KiB 页：压缩率回归 +17%（ratio 0.128），读放大更小但文件更大、页索引占比更高。
- 64 KiB 页：压缩率仅再 ~2% 更好，但冷读解压翻倍（64 KiB），与 32 区分歧不大。
- 无页索引、保持 O(ordinal) RecordAt：热点读劣化严重（实测 ~40µs），不采纳。
